\chapter*{Resumen}

\noindent Este proyecto se centra en el diseño, desarrollo e implementación de Dixi, un sistema que toma secuencias de pictogramas (símbolos visuales que representan conceptos, acciones u objetos) del catálogo ARASAAC (Centro Aragonés para la Comunicación Aumentativa y Alternativa) y produce frases naturales en español.

Para construirlo se implementan y comparan tres técnicas de generación de texto. La primera parte de reglas gramaticales explícitas que describen cómo se combinan las palabras para formar una oración correcta en español. Como segunda técnica, se propone una metodología propia que selecciona y combina las palabras adecuadas basándose en \textit{embeddings} (vectores donde conceptos parecidos tendrán valores similares y conceptos distintos no). La tercera recurre a un modelo de lenguaje de gran escala, un sistema de inteligencia artificial entrenado con grandes cantidades de texto capaz de redactar frases naturales a partir de palabras clave.

Sobre estas tres aproximaciones se construyen tres motores híbridos que las combinan para corregir los puntos débiles de cada una.

La técnica más adecuada se elige por dos vías: métricas automáticas calculadas sobre 164 casos de prueba con varias frases de referencia recogidas de hablantes nativos, y una encuesta en la que personas reales eligen, sin saber qué motor produjo cada frase, cuál les suena más natural. El modelo de lenguaje encabeza ambas evaluaciones, con el 44\% de las preferencias humanas y una ventaja estadísticamente significativa frente al resto.

Dixi se entrega como una aplicación móvil multiplataforma desarrollada con \texttt{React Native} y \texttt{Expo}, que permite construir frases seleccionando pictogramas en pantalla y reproduce el resultado en habla mediante un motor de síntesis de voz.

A lo largo de esta memoria se describen los pasos seguidos durante el estudio y el desarrollo del sistema, las tecnologías consideradas y las comparativas entre ellas, así como las pruebas realizadas y las conclusiones obtenidas.
