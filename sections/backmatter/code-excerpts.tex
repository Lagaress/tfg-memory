\section{Inferencia de elementos faltantes}

El fragmento central del postprocesador es el método de inferencia (sección~\ref{sec:f1-postprocesamiento}). Cuando la entrada consiste en un solo objeto o un solo lugar, el sistema inserta los elementos verbales que el usuario de CAA omite. Cada inferencia queda registrada con su tipo, valor y razón, lo que permite trazar las decisiones del sistema.

\begin{lstlisting}[language=Python,caption={Inferencia de elementos faltantes (\texttt{postprocessor.py}).},label={lst:inferencia},basicstyle=\ttfamily\small,xleftmargin=1cm]
def _inferir_elementos(self, palabras, contexto):
    resultado = list(palabras)
    inferencias = []

    if contexto.tipo_oracion == "necesidad" and len(resultado) == 1:
        # "baño" -> ["quiero", "ir", "baño"]
        if self.lexicon.es_lugar(resultado[0].lower()):
            resultado = ["quiero", "ir"] + resultado
            inferencias.append(InferenciaAplicada(
                tipo="verbo_necesidad",
                valor_inferido="quiero",
                posicion=0,
                razon="Lugar solo implica quiero ir"
            ))
            inferencias.append(InferenciaAplicada(
                tipo="verbo_movimiento",
                valor_inferido="ir",
                posicion=1,
                razon="Lugar solo implica movimiento"
            ))
        # "agua" -> ["quiero", "agua"]
        elif self.lexicon.es_objeto(resultado[0].lower()):
            resultado = ["quiero"] + resultado
            inferencias.append(InferenciaAplicada(
                tipo="verbo_necesidad",
                valor_inferido="quiero",
                posicion=0,
                razon="Objeto solo implica necesidad"
            ))

    return resultado, inferencias
\end{lstlisting}

\section{Concordancia de género}

La concordancia de género (sección~\ref{sec:f1-postprocesamiento}) busca hacia atrás desde cada adjetivo hasta encontrar el sustantivo al que modifica, obtiene su género y transforma el adjetivo si es necesario. Los adjetivos invariables (\textit{feliz}, \textit{triste}, \textit{azul}) se mantienen inalterados.

\begin{lstlisting}[language=Python,caption={Concordancia de género en adjetivos (\texttt{postprocessor.py}).},label={lst:concordancia},basicstyle=\ttfamily\small,xleftmargin=1cm]
def _aplicar_concordancia(self, palabras, contexto):
    resultado = []
    for i, palabra in enumerate(palabras):
        if self.lexicon.es_adjetivo(palabra.lower()):
            genero = self._encontrar_genero_sustantivo(
                palabras, i
            )
            if genero:
                resultado.append(
                    self._concordar_adjetivo(palabra, genero)
                )
                continue
        resultado.append(palabra)
    return resultado

def _concordar_adjetivo(self, adjetivo, genero):
    adjetivos_invariables = {
        "feliz", "triste", "alegre", "grande",
        "azul", "verde", "bien", "mal",
    }
    if adjetivo in adjetivos_invariables:
        return adjetivo
    # "cansado" + femenino -> "cansada"
    if adjetivo.endswith("o") and genero == "femenino":
        return adjetivo[:-1] + "a"
    # "roja" + masculino -> "rojo"
    if adjetivo.endswith("a") and genero == "masculino":
        return adjetivo[:-1] + "o"
    return adjetivo
\end{lstlisting}

El módulo \texttt{cfg\_bridge.py} encapsula toda la comunicación con el motor de gramática formal (sección~\ref{sec:f2-pipeline}).         if src_path not in sys.path:

\section{Composición vectorial ponderada}

La estrategia de composición vectorial por defecto (sección~\ref{sec:f2-embeddings}) pondera las palabras según su tipo: las de contenido (sustantivos, verbos, adjetivos) reciben peso 1,0 y las funcionales (artículos, preposiciones) reciben peso 0,3. Esta ponderación refleja que en CAA el usuario selecciona deliberadamente las palabras de contenido, mientras que las funcionales las infiere el sistema.

\begin{lstlisting}[language=Python,caption={Composición vectorial ponderada (\texttt{vector\_composer.py}).},label={lst:weighted-average},basicstyle=\ttfamily\small,xleftmargin=1cm]
def weighted_average(self, tokens):
    token_vectors = self._get_token_vectors(tokens)
    if not token_vectors:
        return np.zeros(self.dim)

    CONTENT_WEIGHT = 1.0
    STOPWORD_WEIGHT = 0.3

    weighted_sum = np.zeros(self.dim)
    total_weight = 0.0

    for token, vec in token_vectors:
        weight = (STOPWORD_WEIGHT
                  if is_stopword(token)
                  else CONTENT_WEIGHT)
        weighted_sum += weight * vec
        total_weight += weight

    if total_weight == 0:
        return np.zeros(self.dim)
    return weighted_sum / total_weight
\end{lstlisting}

\section{Ranking semántico de candidatos}

El método \texttt{score\_candidate()} (sección~\ref{sec:f2-pipeline}) calcula el score de embeddings combinando preferencia seleccional (60\%) y similitud vectorial a nivel de oración (40\%). El método \texttt{rank\_candidates()} aplica la fórmula de score combinado con la confianza de la CFG y ordena los candidatos.

\begin{lstlisting}[language=Python,caption={Scoring y ranking de candidatos (\texttt{semantic\_scorer.py}).},label={lst:ranking-candidatos},basicstyle=\ttfamily\small,xleftmargin=1cm]
def score_candidate(self, candidate, pictogram_labels):
    sentence_tokens = tokenize_sentence(
        candidate["sentence"]
    )
    verbs, nouns = self._find_verbs_and_nouns(
        sentence_tokens
    )

    # Preferencia seleccional (60%)
    sel_score = 0.0
    if verbs and nouns:
        scores = []
        for verb in verbs:
            inf = self._resolve_infinitive(verb) or verb
            for noun in nouns:
                scores.append(
                    self.compute_selectional_preference(
                        inf, noun
                    )
                )
        sel_score = float(np.mean(scores))

    # Similitud vectorial oracion (40%)
    vec_score = 0.0
    input_vec = self.vector_composer.weighted_average(
        pictogram_labels
    )
    sent_vec = self.vector_composer.weighted_average(
        sentence_tokens
    )
    if np.any(input_vec) and np.any(sent_vec):
        vec_score = float(
            cosine_similarity(input_vec, sent_vec)
        )

    return sel_score * 0.6 + vec_score * 0.4

def rank_candidates(self, candidates, pictogram_labels):
    for candidate in candidates:
        emb_score = self.score_candidate(
            candidate, pictogram_labels
        )
        candidate["embedding_score"] = emb_score
        candidate["combined_score"] = (
            candidate["confianza"] * 0.6
            + emb_score * 0.4
        )
    candidates.sort(
        key=lambda c: c["combined_score"], reverse=True
    )
    return candidates
\end{lstlisting}

\section{Predicción de preposiciones por prototipos vectoriales}

El predictor de preposiciones (sección~\ref{sec:f2-preposiciones}) calcula el vector de contexto sumando los embeddings del verbo y el sustantivo, y selecciona la preposición cuyo prototipo tiene mayor similitud coseno. Si ningún prototipo supera el umbral mínimo, recurre a la preposición por defecto del verbo.

\begin{lstlisting}[language=Python,caption={Predicción de preposiciones (\texttt{semantic\_scorer.py}).},label={lst:predict-preposition},basicstyle=\ttfamily\small,xleftmargin=1cm]
def predict_preposition(self, verb, noun):
    verb_inf = self._resolve_infinitive(verb) or verb

    if not self.preposition_prototypes:
        if verb_inf in self._verb_prepositions:
            return (self._verb_prepositions[verb_inf],
                    0.8, "rule_verb")
        return (None, 0.0, "none")

    verb_emb = self.embedding_loader.get_word_vector(
        verb_inf
    )
    noun_emb = self.embedding_loader.get_word_vector(
        noun.lower()
    )

    if verb_emb is not None and noun_emb is not None:
        context_vector = verb_emb + noun_emb
        best_prep, best_score = None, -1.0

        for prep, prototype in \
                self.preposition_prototypes.items():
            score = cosine_similarity(
                context_vector, prototype
            )
            if score > best_score:
                best_score = score
                best_prep = prep

        if best_prep and best_score >= 0.15:
            return (best_prep, best_score, "embedding")

    # Fallback: regla por verbo
    if verb_inf in self._verb_prepositions:
        return (self._verb_prepositions[verb_inf],
                0.8, "rule_verb")
    return (None, 0.0, "none")
\end{lstlisting}

\section{Preferencia seleccional con embeddings}

La preferencia seleccional (sección~\ref{sec:f2-pipeline}) mide la compatibilidad semántica entre un verbo y su argumento mediante la similitud coseno de sus embeddings. El umbral de 0,10 es deliberadamente bajo para admitir combinaciones válidas pero infrecuentes en el contexto de CAA.

\begin{lstlisting}[language=Python,caption={Preferencia seleccional (\texttt{semantic\_scorer.py}).},label={lst:selectional-preference},basicstyle=\ttfamily\small,xleftmargin=1cm]
def compute_selectional_preference(self, verb, argument):
    verb_emb = self.embedding_loader.get_word_vector(verb)
    arg_emb = self.embedding_loader.get_word_vector(
        argument
    )
    if verb_emb is None or arg_emb is None:
        return 0.0
    return cosine_similarity(verb_emb, arg_emb)

def validate_combination(self, verb, argument):
    score = self.compute_selectional_preference(
        verb, argument
    )
    return score >= self.selectional_threshold  # 0.10
\end{lstlisting}

    "poder": ["pued"],

    "dormir": ["duerm"],
    "jugar": ["jueg"],
    "ir": ["voy", "vas", "va", "vamos", "van"],
    "ser": ["soy", "eres", "es", "somos", "son"],
    # ... (12 verbos irregulares)
}

def _matches_concept(pictogram, text, text_words):
    # Nivel 1: subcadena exacta
    if pictogram in text:
        return True

    # Nivel 2: raiz de 4 caracteres
    if len(pictogram) >= 4:
        if pictogram[:4] in text:
            return True

    # Nivel 3: raices irregulares
    for alt in _IRREGULAR_STEMS.get(pictogram, []):
        if alt in text:
            return True

    # Nivel 4: raiz de 3 caracteres (fallback)
    if len(pictogram) >= 3:
        stem3 = pictogram[:3]
        if any(w.startswith(stem3) for w in text_words):
            return True

    return False
\end{lstlisting}

\section{Cliente de API con reintentos}

El cliente de la API (sección~\ref{sec:f3-cliente}) gestiona los reintentos diferenciados según el tipo de error, mide la latencia con precisión de milisegundos y estima el coste de cada llamada a partir de los precios por token.

\begin{lstlisting}[language=Python,caption={Cliente de API con reintentos y estimación de coste (\texttt{llm\_client.py}).},label={lst:llm-client},basicstyle=\ttfamily\small,xleftmargin=1cm]
def generate(self, messages):
    start_time = time.perf_counter()

    for attempt in range(self.config.max_retries + 1):
        try:
            response = self.client.chat.completions.create(
                model=self.config.name,
                messages=messages,
                max_tokens=self.config.max_tokens,
                temperature=self.config.temperature,
                top_p=self.config.top_p,
                timeout=self.config.timeout,
            )
            latency_ms = (
                time.perf_counter() - start_time
            ) * 1000
            text = response.choices[0].message \
                          .content.strip()
            usage = response.usage

            return {
                "text": text,
                "latency_ms": round(latency_ms, 2),
                "tokens_input": usage.prompt_tokens,
                "tokens_output": usage.completion_tokens,
                "cost_usd": self._estimate_cost(
                    usage.prompt_tokens,
                    usage.completion_tokens
                ),
                "success": True,
            }
        except RateLimitError:
            if attempt < self.config.max_retries:
                wait = 2 ** (attempt + 1)
                time.sleep(wait)
                continue
        except APITimeoutError:
            if attempt < self.config.max_retries:
                continue

def _estimate_cost(self, input_tokens, output_tokens):
    prices = {
        "gpt-4o": {
            "input": 2.50 / 1_000_000,
            "output": 10.00 / 1_000_000
        },
        "gpt-4o-mini": {
            "input": 0.15 / 1_000_000,
            "output": 0.60 / 1_000_000
        },
    }
    p = prices.get(self.config.name)
    return round(
        input_tokens * p["input"]
        + output_tokens * p["output"], 8
    )
\end{lstlisting}

\section{Pipeline de Hibridación 1}

La Hibridación 1 (sección~\ref{sec:h-hybrid1}) conecta la gramática formal con el post-editor LLM en dos pasos. Si la gramática tiene éxito, la frase se post-edita; si falla, el post-editor genera desde cero. El campo \texttt{method} del resultado distingue ambos caminos.

\begin{lstlisting}[language=Python,caption={Pipeline Gramática + LLM (\texttt{grammar\_llm.py}).},label={lst:hybrid1-pipeline},basicstyle=\ttfamily\small,xleftmargin=1cm]
def generate(self, pictograms):
    self._ensure_setup()
    total_start = time.perf_counter()

    # Paso 1: generar con gramatica formal
    try:
        resultado = self._generator.generate(pictograms)
        grammar_success = (
            not resultado.error and bool(resultado.opciones)
        )
        grammar_sentence = (
            resultado.opciones[0].frase
            if grammar_success else ""
        )
    except Exception as e:
        grammar_success = False
        grammar_sentence = ""

    # Paso 2: post-editar o fallback
    if grammar_success:
        pe_result = self._post_editor.post_edit(
            grammar_sentence, pictograms
        )
        method = "grammar_post_edit"
    else:
        pe_result = self._post_editor.generate_direct(
            pictograms
        )
        method = "fallback_llm_direct"

    return Hybrid1Result(
        sentence=pe_result.edited_sentence,
        method=method,
        grammar_sentence=grammar_sentence,
        grammar_success=grammar_success,
        llm_was_modified=pe_result.was_modified,
        total_latency_ms=(
            time.perf_counter() - total_start
        ) * 1000,
    )
\end{lstlisting}

\section{Pipeline de Hibridación 3}

La Hibridación 3 (sección~\ref{sec:h-hybrid3}) implementa el paradigma \textit{overgenerate-and-rank}: genera cinco candidatas con los cinco motores, filtra por cobertura de pictogramas y selecciona la de menor perplejidad.

\begin{lstlisting}[language=Python,caption={Pipeline Overgenerate-and-Rank (\texttt{overgenerate\_rank.py}).},label={lst:hybrid3-pipeline},basicstyle=\ttfamily\small,xleftmargin=1cm]
def generate(self, pictograms):
    self._ensure_setup()

    # Etapa 1: sobregeneracion (5 motores)
    raw_candidates = [
        self._generate_grammar(pictograms),
        self._generate_embeddings(pictograms),
        self._generate_llm(pictograms),
        self._generate_hybrid1(pictograms),
        self._generate_hybrid2(pictograms),
    ]
    candidates = [
        c for c in raw_candidates if c["sentence"]
    ]

    # Etapa 2: filtro de fidelidad
    scored = self._fidelity_filter.score_all(
        candidates, pictograms
    )
    filtered = [
        c for c in scored if c.fidelity_passed
    ]

    # Fallback: si ninguna pasa, rankear todas
    to_rank = filtered if filtered else scored

    # Etapa 3: ranking por perplejidad
    ranked = self._ranker.rank(to_rank)
    best = ranked[0]

    return Hybrid3Result(
        sentence=best.sentence,
        best_source=best.source,
        best_perplexity=best.perplexity,
        all_candidates=scored,
        ranked_candidates=ranked,
    )
\end{lstlisting}

\section{Ranking por perplejidad con normalización}

El ranker (sección~\ref{sec:h-hybrid3}) ordena las candidatas por perplejidad ascendente. GPT-2 asigna perplejidad menor a frases con punto final (por ejemplo, 70 frente a 181 para la misma frase), por lo que el ranker elimina la puntuación terminal antes del cálculo para evitar que las frases del post-editor, que siempre añaden punto, ganen automáticamente.

\begin{lstlisting}[language=Python,caption={Ranking con normalización de puntuación (\texttt{ranker.py}).},label={lst:perplexity-ranker},basicstyle=\ttfamily\small,xleftmargin=1cm]
def rank(self, candidates):
    self._ensure_scorer()
    sentences = [c.sentence for c in candidates]

    # Normalizar puntuacion terminal para el scoring.
    # GPT-2 asigna perplejidad mucho menor a frases
    # con punto final, sesgando el ranking.
    normalized = [
        re.sub(r'[.!?]+$', '', s).strip()
        for s in sentences
    ]

    # Perplejidad en batch (frases normalizadas)
    perplexities = self._scorer.score(normalized)

    ranked = []
    for i, c in enumerate(candidates):
        ranked.append(RankedCandidate(
            sentence=sentences[i],
            source=c.source,
            perplexity=perplexities[i],
            coverage_score=c.coverage_score,
        ))

    ranked.sort(key=lambda r: r.perplexity)
    for i, r in enumerate(ranked):
        r.rank = i + 1
    return ranked
\end{lstlisting}
